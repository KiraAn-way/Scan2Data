# Privacy Draft

Draft only. Needs final review before store publish.

## Overview

Scan2Data is intended for warehouse and logistics scan work.

The app may process barcode values, item/article numbers, inventory list rows, packing list rows, dictionary entries, printer settings, and usage counters needed for the selected workflow.

## Data Handling

Data may be entered by:

- hardware scanner/Data Intent
- Android camera scanner
- manual input
- imported files from the device or OneDrive
- bundled example files
- configured SMB/network folders

The app may store local working files for scan history, imported lists, dictionary data, printer configuration, license/demo state, and usage analytics.

This public notes repo does not include user data, customer data, credentials, private paths, or internal settings.

## Permissions

The current app may use permissions related to:

- camera scanning
- foreground service operation
- notifications
- Bluetooth printer access
- network access for WiFi printing and SMB file browsing
- file access through Android document picker flows

Exact permission text and store disclosures must be checked again before release.

## Network Use

Network features can include:

- WiFi printer communication
- optional SMB/network folder browsing and file import

Public documentation must not include private infrastructure details, credentials, or customer-specific paths.

## Analytics

The app includes basic usage analytics for operational counts and exportable summaries where enabled. Analytics behavior should be reviewed before public release and described in final store privacy text.
