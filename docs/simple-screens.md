# Simple Screen Notes

Rough screen notes. Not full designs, just the idea.

## Main Screen

Shows what is going on with scanning.

May have:

- Last scanned value
- Queue or processing status
- Recent scan selector
- Manual code entry
- Tools area

## Options Screen

App settings.

May have:

- Input source selection
- Printer or workflow profile selection
- Language selection
- Directory or data source settings

## WiFi Printer Screen

For saved printer targets.

May have:

- Saved printer list
- Printer name
- IP address
- Port
- Save, remove, and select actions

## Directory Screen

For data source settings.

May have:

- Directory access information
- Update dictionary action
- Update packing list action

## Camera Scan Screen

Fallback scan screen with camera.

May have:

- Camera preview
- Scan instruction text
- Automatic return after a valid scan
